
# TechShop

TechShop es una tienda online de tecnología construida con React. Los usuarios pueden navegar el catálogo, buscar productos, revisar el stock disponible de cada item y administrar su carrito de compras, todo desde una interfaz responsive y fluida. [Ver sitio](https://tech-shop-daddese.netlify.app/)

---

## Funcionalidades

-  **Búsqueda de productos** en tiempo real
-   **Carrito de compras** con persistencia en LocalStorage
-   **Control de stock** por producto
-   **Diseño responsive** para todos los dispositivos
-   **Estado global** manejado con Context API

---

## Tecnologías utilizadas

-   **React** — Biblioteca principal para la construcción de la UI
-   **Context API** — Manejo del estado global (carrito, productos)
-   **Custom Hooks** — Lógica reutilizable encapsulada
-   **LocalStorage** — Persistencia del carrito entre sesiones
-   **React Router** — Navegación entre vistas
-   **CSS / Responsive Design** — Adaptable a móvil, tablet y escritorio
-   **React Spinners** (loader animado)
